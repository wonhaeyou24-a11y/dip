## 0. 이 문서의 목적

- 개발에 착수하기 전에 전체 구조·데이터·측정 알고리즘·단계별 계획을 한 곳에 정리한다.

## 1. 프로그램 개요

### 1.1 한 줄 정의
현장에서 스마트폰으로 불연속면의 주향·경사를 측정하고, 절리상태를 조사하고, 사진·GPS와 함께 저장한 뒤, 사무실에서 Excel로 출력하는 **현장조사 전용 앱**.

### 1.2 기본 흐름
```
현장 도착
  → 프로젝트 선택 / 생성
  → 조사위치(측점) 생성  (GPS 자동)
  → 불연속면 추가
       → 주향·경사 측정 (스마트폰 센서, 자동)
       → 측정 신뢰도 확인 / 필요시 재측정
       → 절리상태 조사 입력
       → 사진 촬영 (전경 / 근접 / 측정화면 / 위치)
       → 저장
  → 다음 불연속면 …
  → 조사 완료
  ─────────────────────────
사무실
  → 데이터 확인 / 수정
  → Excel 출력
  → (STEP 7) 보고서 출력
```

### 1.3 목표 (In Scope)
- 스마트폰 센서 기반 주향·경사 자동 측정 + 신뢰도 표시 + 수동 입력/보정
- ISRM + 국내 기준 기반 절리상태 조사 (항목은 첨부자료로 확정)
- 사진 + GPS + 조사자 + 조사일 기록, 항목 간 연결
- **완전 오프라인 동작** (현장 인터넷 불필요)
- 데이터 수정/삭제 및 측정 이력 보관
- Excel 출력 (측점별 / 불연속면별)

### 1.4 비목표 (Out of Scope, 최소 1차 개발에서 제외)
- 사무실 전용 모드(별도 PC UI) — 만들지 않음. 같은 앱에서 목록/수정/출력만 제공.
- 극점도·장미도·절리군 자동분류·RMR/SMR/Q — **STEP 6에서 필요성 검토 후 결정.** 지금은 데이터 구조만 확장 가능하게 잡는다.
- 클라우드 동기화(Supabase) — STEP 4 이후 선택적. 1차에서는 로컬 저장 + 내보내기/가져오기로 충분.
- 보고서 자동생성·AI 분석 — STEP 7, 사용자가 실제 보고서 양식을 준 뒤 설계.
- 다중 사용자 협업, 로그인, 권한관리.

### 2.1 아키텍처
```
[스마트폰 브라우저 / 설치된 PWA]
        │
   React UI (현장모드 화면)
        │
   ├── SensorService   (주향·경사 측정 엔진)
   ├── GeoService      (GPS)
   ├── CameraService   (사진)
   └── Repository (Dexie) ── IndexedDB (프로젝트/측점/불연속면/사진/이력)
        │
   ExportService (ExcelJS) → .xlsx 다운로드
        │
   (선택) SyncService → Supabase
```

### 2.2 주요 기기 제약 (반드시 인지)
- **HTTPS 필수** — 센서/카메라/GPS 모두. 로컬 개발은 `localhost` 예외.
- **iOS 13+**: `DeviceOrientationEvent.requestPermission()` 를 사용자 탭 이벤트에서 호출해야 센서 동작. iOS는 `webkitCompassHeading`(진북 기준 방위) 제공.
- **Android**: `deviceorientationabsolute` 이벤트의 `alpha`는 **자북 기준**. → **자기편각(declination) 보정 필요**.
- 기기별 센서 품질 편차 큼. 자기장 간섭(철근, 차량, 자철석)에 취약 → 신뢰도 표시와 수동 보정이 필수.

## 4. STEP 2 — 주향·경사 측정 엔진 (가장 먼저 기술검증)

### 4.1 측정 원리 (설계안)
1. 사용자가 **스마트폰 뒷면을 불연속면에 밀착**. 화면은 암반 반대쪽(하늘 쪽)을 향함.
2. 브라우저가 자이로+가속도+지자기 융합 방위(회전행렬 R, 기기→ENU 세계좌표)를 제공.
3. 기기 +Z축(화면 바깥, 뒷면 밀착 시 암반 바깥 방향) = **불연속면의 법선(pole)**.
   - 세계좌표 법선 `n = R · (0,0,1)ᵀ = (nE, nN, nU)`.
   - `nU < 0` 이면 부호 반전(위를 향하도록).
4. **경사각** `dip = atan2(√(nE²+nN²), nU)` (도, 0~90). (수평면 pole=수직 → dip 0, 수직면 → dip 90)
5. **경사방향** `dipDirection = atan2(nE, nN)` → 0–360° 정규화.
   (동쪽 경사면의 상방 법선은 동쪽 성분을 가짐 → 경사방향 090)
6. **주향** `strike = (dipDirection − 90 + 360) mod 360` (우수법).
   ※ 구현·검증 완료: `src/lib/sensors/orientation.ts` (테스트 15건 통과).
7. **진북 보정**: Android `alpha`(자북) 사용 시 GPS 좌표로 자기편각을 구해 더한다.
   iOS `webkitCompassHeading` 은 이미 진북 → 보정 불필요(플래그로 구분).

### 4.2 안정화 & 신뢰도 알고리즘 (설계안)
- 측정 버튼 → 최근 N=20–40 샘플(약 1–2초) 수집.
- **안정도**: 최근 샘플의 dip / dipDir 표준편차.
  - std(dip) < 1° 이고 std(dipDir) < 2° → 🟢 양호
  - 그 외 → 🟡 주의 (움직임)
- **자기장 간섭**: 지자기 센서 정확도 필드(`Sensor.accuracy` / iOS 는 heading accuracy), 총 자기장 세기가 지역 정상범위(≈ 45–55 µT)를 벗어나면 🟡/🔴.
- **채택값**: 안정 구간 샘플의 (원형)평균.
- 🔴 이거나 사용자가 원하면 **재측정**. 모든 시도는 `measurementLogs` 에 남긴다.
- **항상 수동 입력/미세보정 가능** (센서 실패·간섭 대비).

### 4.3 검증 방법 (STEP 2 완료 기준)
1. 기준 자세 테스트: 수평 책상(dip≈0), 벽에 수직(dip≈90), 알려진 각도의 경사면.
2. 실물 컴퍼스(클리노미터) 또는 기존 앱과 **동일 면 10회** 비교.
   - 목표 허용오차(문헌 기준): **경사 ±2°, 경사방향 ±3°** 수준 (양호 조건).
   - 참고: Smart Compass-Clinometer 연구 — 야외에서 실측 대비 평균차 경사 1.70°, 경사방향 2.63°. Weinberg 등 스마트폰 앱 정밀도 연구.
3. 자기장 간섭 상황(차량 옆, 철제 구조물)에서 경고가 뜨는지 확인.
4. Android/iOS 기기 각 1대 이상에서 재현.

### 4.4 STEP 2 위험요소
| 위험 | 영향 | 대응 |
|---|---|---|
| 기기별 센서 정확도 편차 | 측정값 신뢰도 | 신뢰도 표시 + 실물 대비 캘리브레이션 절차 문서화 + 수동보정 |
| 자기장 간섭 | 경사방향 오차 큼 | µT 세기·센서 accuracy 기반 경고, 8자 캘리브레이션 안내 |
| iOS/Android API 파편화 | 구현 복잡도 | 헤딩 소스 추상화(SensorService), 진북/자북 플래그 |
| 브라우저 권한/HTTPS | 센서 미동작 | 배포부터 HTTPS, iOS 권한 요청 UX |
| 밀착 자세 오차(사용자) | 재현성 | 3점 측정/평균, 근접사진으로 사후 검증 |

## 10. 개발 진행 방식

```
기능 정의
 → 필요한 조사기준·기술자료 확인 (근거 확보)
 → 자료 비교 → 적용 기준 결정
 → 개발계획 반영
 → Claude로 해당 단계만 개발 (한 번에 거대 코드 X)
 → 실제 스마트폰에서 실행·테스트
 → 기존 기준/실측과 비교
 → 문제 수정 → 다음 단계
```
- 각 STEP은 독립적으로 실행·테스트 가능한 상태로 마감.
- Git 저장소로 관리(현재 미초기화 → STEP 1 확정 시 `git init`).
- STEP 2(측정 엔진)와 STEP 5·7(첨부자료 의존)이 최우선 리스크.

## 11. 참고자료

### 11.1 확보/확인한 자료
- **ISRM Suggested Methods for the Quantitative Description of Discontinuities in Rock Masses (1978, 1981 개정)** — 불연속면 10개 파라미터(방향, 간격, 연속성, 거칠기, 벽면강도, 개구, 충전물, 용수, 절리군 수, 블록 크기)의 정의·등급. 절리상태 조사 항목의 1차 근거.
- **ISRM Suggested Methods 통합본 (Ulusay ed., 1974–2006 / 2007–2014)** — 최신 개정 반영본.
- **Smart Compass-Clinometer (Lee et al., 2013, Computers & Geosciences)** — 스마트폰 주향·경사 측정 앱, 실측 대비 정확도(경사 1.70°, 경사방향 2.63°).
- **스마트폰/태블릿 평면 방향 측정 정밀도 평가 연구** (Weinberg 등, "Testing smartphone apps for strike and dip") — 앱별 오차·한계.
- **US Bureau of Reclamation, Engineering Geology Field Manual** — 현장 불연속면 조사 절차, 우수법(right-hand rule), 조사선 기법, 기록·도면화.
- **국내: 「시설물의 안전 및 유지관리 실시 등에 관한 지침」** (국가법령정보센터, 2026-08-21 일부개정·시행).
- **국내: 「시설물의 안전 및 유지관리 실시 세부지침」** (국토안전관리원, 2026-01-23 개정).

### 11.2 단계별로 추가 확인이 필요한 자료
