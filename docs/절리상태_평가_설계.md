## 1. 목표

각 불연속면(절리군)에 대해
1. 세부지침 분류표(표 14.6~14.12)에 따라 **상태값**을 조사·선택하고,
2. **상세 절리 상태표**(§3.1)에 따라 5개 항목별 **점수**를 매기고,
3. `산술평균 = Σ(①~⑤) / 5` (분모 고정 5) → `절리상태 점수 = round(산술평균)` (반올림 정수).

프로그램은 합계·산술평균·절리상태 점수까지 산출한다. 이 점수로 유리·불리를 판단하는 것은 조사자/기술자의 몫.
→ "상세 절리상태표" = 조사항목 + 상태값 선택 + 자동 배점 + 합계 + 산술평균 + 절리상태 점수(정수).

## 2.1 분류표 (세부지침 원문 전사)

### 표 14.6 풍화등급의 6단계 분류법
| 풍화등급 | 설명 | 공학적 특성 |
|---|---|---|
| 신선함 (F) | 암석의 풍화 흔적을 볼 수 없음. 주 불연속면 표면에 경미한 변색이 있을 수 있음 | 발파로 굴착가능 / 모든 구조물 기초로 적합 |
| 약한풍화 (SW) | 불연속면 표면·암석의 변색 상태가 풍화 지표. 불연속면이 얼룩져/변색되어 있고 외부적으로 신선한 상태보다 약함 | 발파로 굴착가능 / 대규모 댐 제외 모든 구조물 기초로 적합 |

| 완전풍화 (CW) | 모든 암석재료가 부스러지거나 흙으로 변함. 단 절리흔적 등 원래 암반 조직은 보존 | Scraping으로 굴착가능 / 토질시험 결과에 따라 기초 사용 결정 |
| 풍화잔류토 (RS) | 모든 암석이 흙으로 변했고 원래 암반 구조·조직 관찰 불가. 큰 부피 변화 생겼으나 흙은 거의 운반되지 않음 | 기초부에 부적합 / 사면침식요인 / 성토재 사용시 재료 선별 |

## 3. 상세 절리 상태표 (배점) — 원문 확정

세부지침 14.2, 항목 7) "절리상태" 하위 표 (p.14-59). **표 번호 없음**(항목 7 본문 표).

> 7) 절리상태는 상세 절리 상태 점수에 대한 산술평균값을 참고하여 유리 및 불리를 평가한다.

### 3.1 배점표 (원문 그대로)

| 구분 | | 상세 절리 상태 | | | |
|---|---|---|---|---|---|
| **① 길이** | < 1 m | 1~3 m 미만 | 3~10 m 미만 | 10~20 m 미만 | ≥ 20 m |
| **② 틈새** | 0 | < 0.1 mm | 0.1~1 mm 미만 | 1~5 mm 미만 | ≥ 5 mm |
| **③ 거칠기** | 매우 거침 | 거침 | 약간 거침 | 평탄 | 매우 평탄 |
| **④ 충전물** | 없음 | 단단한 충전물 (< 5 mm) | 단단한 충전물 (≥ 5 mm) | 연약한 충전물 (< 5 mm) | 연약한 충전물 (≥ 5 mm) |
| **⑤ 풍화도** | 신선 | 약한 풍화 | 보통 풍화 | 심한 풍화 | 완전 풍화 |
| **점수** | **0** | **1~2** | **3~4** | **5~6** | **7~8** |

```
절리상태 점수 P̄ = Σ(①~⑤) / 5
```

### 3.2 배점 규칙 (프로그램 적용 — 사용자 확정)

- 5개 항목 ①~⑤ 는 **항상 모두** 조사한다(미조사 항목 없음).
- 각 항목: 상태값이 속한 **단계(1~5)** 를 고른다.
- 단계 → 점수:
  | 단계 | 1 | 2 | 3 | 4 | 5 |
  |---|---|---|---|---|---|
  | 점수 | **0** | **1 또는 2** | **3 또는 4** | **5 또는 6** | **7 또는 8** |
- **1단계 = 0점(고정).** 2~5단계는 조사자가 현장 상황에 따라 **구간의 두 값 중 하나를 직접 선택**한다.
  (예: 3단계로 판단했고 상태가 그 구간에서 나쁜 쪽 → 4점, 좋은 쪽 → 3점)
  - 프로그램은 단계 선택 시 두 점수 버튼(예: `[3] [4]`)을 띄우고, 조사자가 고른 정수를 저장한다.
- `산술평균 = (P① + P② + P③ + P④ + P⑤) / 5`, **분모는 항상 5** (범위 0.0 ~ 8.0, 소수 1자리).
- **절리상태 점수 = round(산술평균)** — 반올림 정수 (예: `19/5 = 3.8 → 4`). 사용자 확정.
- **등급 산정 안 함.** 합계 · 산술평균 · 절리상태 점수(정수)만 계산·표시·출력.

### 3.3 항목별 상태값 ↔ 세부지침 분류표 대응

| 배점항목 | 1단계 | 2단계 | 3단계 | 4단계 | 5단계 | 대응 분류표 |
|---|---|---|---|---|---|---|
| ① 길이(연장성) | < 1 m | 1~3 m | 3~10 m | 10~20 m | ≥ 20 m | 표 14.8 (등급명 1:1) |
| ② 틈새 | 밀착(0) | < 0.1 mm | 0.1~1 mm | 1~5 mm | ≥ 5 mm | 표 14.10 (밀착/약간벌어짐/벌어짐/약간넓음/넓음) |
| ③ 거칠기 | 매우 거침 | 거침 | 약간 거침 | 평탄 | 매우 평탄 | 표 14.9 (매우거칠음/거칠음/약간거칠음/**매끄러움**/**경면화**) |
| ④ 충전물 | 없음 | 단단 < 5 mm | 단단 ≥ 5 mm | 연약 < 5 mm | 연약 ≥ 5 mm | 표 14.11 (딱딱함/부드러움 = 단단/연약) |
| ⑤ 풍화도 | 신선 | 약한 풍화 | 보통 풍화 | 심한 풍화 | 완전 풍화 | **상세 절리 상태표의 5단계를 직접 사용** (표 14.6 F/SW/MW/HW/CW 참고, RS 미사용) |

> ③ 거칠기: 배점표 문구(평탄/매우 평탄)와 표 14.9 문구(매끄러움/경면화)가 다름 → 프로그램은 두 표기 병기, 같은 단계로 매핑.
> ⑤ 풍화도: 배점은 **상세 절리 상태표 5단계**로 판단(사용자 확정). 표 14.6 은 참고·기록용.

### 4.1 `Condition` 객체

```ts
interface Condition {
  schemaVersion: 3;
  standard: "MOLIT_절토사면_세부지침_2026-01";

  // ── 배점 5개 항목: {단계 1~5, 점수} ──
  // 점수는 단계 1 → 0, 단계 2~5 → 구간 두 값 중 조사자 선택
  persistence: RatedItem;   // ① 길이(연장성)  표 14.8
  aperture:    RatedItem;   // ② 틈새          표 14.10
  roughness:   RatedItem;   // ③ 거칠기        표 14.9
  infilling:   RatedItem;   // ④ 충전물        (재료·두께로부터 단계 산출)
  weathering:  RatedItem;   // ⑤ 풍화도        상세 절리 상태표 5단계

  // ── 부가 실측/기술값 ──
  persistenceValue_m?: number;
  apertureValue_mm?:   number;
  infillingMaterial?:  string;      // 자유 입력 + 추천목록(석영/방해석/점토/단층각력…)
  infillingWidth_mm?:  number;

  // ── 배점 결과 (자동계산·저장) ──
  sum: number;                      // P① + P② + P③ + P④ + P⑤   (0 ~ 40)
  mean: number;                     // 산술평균 = sum / 5  (0.0 ~ 8.0, 소수 1자리)
  score: number;                    // 절리상태 점수 = round(mean)  (정수, 예 3.8 → 4)
  scoringConfigVersion: string;

  freeText: string;
}

interface RatedItem {
  stage: 1 | 2 | 3 | 4 | 5;         // 상세 절리 상태표 단계
  bound: "lower" | "upper";         // 조사자가 구간의 하한/상한 중 선택
  score: number;                    // stage·bound에서 산출: 1→0, 2→{1|2}, 3→{3|4}, 4→{5|6}, 5→{7|8}
}
```

(참고) 배점 미반영 항목 `spacing`(표 14.7)·`seepage`(표 14.12) 는 `Condition` 이 아니라
`DiscontinuitySet.spacing`(Set별) · `Station.seepage`(측점 공통) 에 둔다.

- 상태값을 `stage`(1~5) + `bound`(하한/상한) 로 저장 → 배점표가 곧 데이터. `score` 는 파생값.
- `aperture`, `persistence` 는 실측값 입력 시 범위 매칭으로 `stage` 자동 산출(수동 override 허용).
- `infilling.stage` 는 `infillingMaterial`(없음/단단/연약) + `infillingWidth_mm`(<5 / ≥5) 조합으로 산출:
  없음→1, 단단<5→2, 단단≥5→3, 연약<5→4, 연약≥5→5.
- 5개 항목 모두 필수.

### 4.2 상위 객체

```ts
interface DiscontinuitySet {
  id: string; stationId: string;
  name: string;                         // "Set 1"
  dtype: "절리" | "층리" | "단층" | "편리·엽리" | "기타";
  orientation: { dip: number; dipDirection: number };   // 표기 "DD/DDD" 경사/경사방향
  spacing: SpacingClass;                 // 표 14.7, Set별
  condition: Condition;
  measurements: OrientationMeasurement[];// 개별 센서 측정 (선택, 대표값 산출 근거)
  note: string;
}

interface Station {
  id: string; facilityId: string;
  siteId: string;                        // "Site-A"
  location: string;                      // "측점 58m 비탈면 하부"
  gps?: { lat: number; lon: number; accuracy: number };
  surveyor: string; surveyedAt: number;
  reboundHardness?: number;              // 반발경도 R (값만, 조사자 입력)
  wallStrength_MPa?: number;             // 강도 (조사자 입력, R 자동환산 안 함)
  seepage: SeepageClass;                 // 표 14.12, 측점 공통
  blockSize?: { x: number; y: number; z: number };   // 암괴크기 m
  photos: Photo[];
}

interface Facility { id: string; name: string; client?: string; note?: string; }

type SpacingClass = "s_veryclose"|"s_close"|"s_moderate"|"s_wide"|"s_verywide"; // 표 14.7
type SeepageClass = "g_dry"|"g_damp"|"g_wet"|"g_dropping"|"g_flowing";          // 표 14.12
```

- `spacing` 은 실측(최소/최대/최빈 m) 입력 시 표 14.7 등급 자동, 라벨은 범위 텍스트("0.2 ~ 0.6m")로 출력.
- `reboundHardness`(값만) / `wallStrength_MPa` 는 **각각 조사자 수동 입력**. R→강도 자동환산 안 함 (사용자 확정).
- `blockSize` 는 3개 주요 Set 의 spacing 으로 자동 추정 + 수동 override.

## 5. 점수 산정 엔진

### 5.1 원칙
- 배점표·라벨을 **config 로 분리**(하드코딩 금지). 지침 개정 시 config 교체 + `version` 증가.
- 기존 데이터는 `scoringConfigVersion` 으로 재계산 가능.
- **등급/유리·불리 판정 없음.** 오직 `절리상태 점수 P̄` 만 산출.

### 5.2 config 구조
```ts
interface ScoringConfig {
  version: string;                    // "molit-2026-01-v1"
  denominator: 5;                     // 고정
  stageBands: [                       // 단계 → 선택 가능한 점수
    { stage: 1, scores: [0] },
    { stage: 2, scores: [1, 2] },
    { stage: 3, scores: [3, 4] },
    { stage: 4, scores: [5, 6] },
    { stage: 5, scores: [7, 8] },
  ];
  items: { key: "persistence"|"aperture"|"roughness"|"infilling"|"weathering";
           labels: [string,string,string,string,string] }[];  // 단계별 표시 문구
}
```

### 5.3 계산 로직
```
5개 항목 모두 { stage, score } 입력 필수.
  단계 1 → score = 0 (자동)
  단계 2~5 → score = 조사자가 stageBands[stage].scores 중 선택
sum   = persistence.score + aperture.score + roughness.score + infilling.score + weathering.score
score = round(sum / 5, 1)            // 절리상태 점수 P̄, 분모 고정 5, 소수 1자리
```

### 5.4 기본 config 값
```
version: molit-2026-01-v1,  denominator: 5
stageBands: [ [0], [1,2], [3,4], [5,6], [7,8] ]
items:
  persistence(①길이): ["<1m", "1~3m", "3~10m", "10~20m", "≥20m"]
  aperture(②틈새):    ["밀착(0)", "<0.1mm", "0.1~1mm", "1~5mm", "≥5mm"]
  roughness(③거칠기): ["매우 거침", "거침", "약간 거침", "평탄(매끄러움)", "매우 평탄(경면)"]
  infilling(④충전물): ["없음", "단단 <5mm", "단단 ≥5mm", "연약 <5mm", "연약 ≥5mm"]
  weathering(⑤풍화도):["신선", "약한 풍화", "보통 풍화", "심한 풍화", "완전 풍화"]
```
예) ① 3단계·4점 + ② 2단계·1점 + ③ 1단계·0점 + ④ 1단계·0점 + ⑤ 2단계·2점
    → sum = 7 → **P̄ = 7 / 5 = 1.4**

## 6. 현장 입력 UI (절리상태 조사 폼)

한 화면, 각 항목 5칸 세그먼트 버튼. 선택 즉시 하단에 P̄ 실시간.

```
┌─────────────────────────────────┐
│  S-001 / J-003   절리상태         │
├─────────────────────────────────┤
│ ① 길이   [<1m][1-3][3-10][10-20][≥20]   (📏 실측 __ m)
│          → 3단계 선택됨   점수 [3][4]      ← 조사자 선택
│ ② 틈새   [밀착][<0.1][0.1-1][1-5][≥5]mm  (📏 __ mm)
│          → 2단계   점수 [1][2]
│ ③ 거칠기 [매우거침][거침][약간][평탄][매우평탄]
│          → 1단계   점수 0 (자동)
│ ④ 충전물 재료[없음][단단][연약] 두께[<5mm][≥5mm] 재료명__
│          → 1단계   점수 0 (자동)
│ ⑤ 풍화   [신선][약한][보통][심한][완전]
│          → 2단계   점수 [1][2]
├─────────────────────────────────┤
│ ─ 기록 전용 (배점 미반영) ─       │
│ 간격  최소__ 최대__ 최빈__ m  [등급 자동]
│ 누수  [건조][습함][젖음][방울][흐름]
│ 특이사항 [__________________]
├─────────────────────────────────┤
│  Σ = 3+1+0+0+2 = 6                │
│  절리상태 점수 P̄ = 6 / 5 = 1.2   │
│  [ 저장 ]                        │
└─────────────────────────────────┘
```
- 단계 선택 → 2~5단계면 점수 2개 버튼 표시(조사자 필수 선택), 1단계면 0점 자동.
- 5개 항목 모두 필수. 미입력 시 노랑 테두리 + "① 길이 미입력" 안내, 저장 차단(또는 경고).
- 실측값(m/mm) 입력 → 해당 단계 자동 선택(수동 override 가능). 점수는 조사자가 구간에서 선택.
- ④ 충전물: 재료=없음이면 두께 비활성 + 자동 1단계·0점.

## 8. 확정 완료 / 남은 것

**확정 (사용자, 2026-09-03)**
1. 구간 점수(1~2 등): 조사자가 현장 상황에 따라 두 값 중 하나 직접 선택 → 프로그램은 점수 2개 버튼 제공.
2. 미조사 항목 없음 → 분모 항상 5, 5개 항목 모두 필수.
3. **등급 산정 안 함.** 절리상태 점수 P̄(0.0~8.0)만 계산·표시·출력.
4. 풍화도는 상세 절리 상태표 5단계(신선/약한/보통/심한/완전)로 판단. 표 14.6·RS는 참고·기록용.

5. 절리상태점수 = round(산술평균) — 확정.
6. 강도: 반발경도 R(값만)·강도(MPa) **각각 조사자 입력**, 자동환산 없음 — 확정.
7. 간격: **Set별**, 표 14.7 등급을 Set 조사 시 선택 — 확정.
8. 파일/시트: 시설물별 파일 1개, 측점은 한 시트에 세로 정리 — 확정.
9. 조사 사진 7종(조사 전경 ①②, 절리측정, 거칠기, 슈미트, 주향/경사, 점검망치), **측점 단위** — 확정.

**사소한 잔여**
- 배점표 표 번호: 본문 항목 7 하위 표(번호 없음).
- 항목 ① 명칭: 원문 "길이/연장성" 병기.
